# Murchison House 采集速查
- 地点：爱丁堡大学 Murchison House（靠 KB 校区），室内公共走廊为主。
- 楼层：建议从一层主走廊开始，若时间允许再上二层；单层完成一圈再换层。
- 步长/节奏：自然步速，尽量匀速；每段直线 20–30 秒，整段录制控制在 8–12 分钟。
- ADD MARKER：
  - 出发点按一次（TP1），
  - 楼梯/转角/楼层切换各按一次，
  - 返回起点或结束点再按一次。
- 录制前：关闭省电/节电模式，确认 Wi‑Fi/BLE/GNSS 已开启，权限已授权。
- 录制中：保持手机外露，不要放包里；若 GNSS 信号弱，仍继续走完路线。
- 录制结束：停在开阔处再点 Stop，等待上传完成提示；若失败保留本地文件。
