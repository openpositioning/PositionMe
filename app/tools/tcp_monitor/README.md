TCP Monitor for PositionMe live debugging

Run:
python Tcp_Client.py

Recommended settings:
- Listen IP: 0.0.0.0
- Port: 6000

Android app should connect to:
- serverIp = <laptop IPv4 address>
- serverPort = 6000

Displays:
- PDR x/y
- accelerometer
- gyroscope
- Wi-Fi AP list summary
- Wi-Fi lat/lng/x/y/floor
